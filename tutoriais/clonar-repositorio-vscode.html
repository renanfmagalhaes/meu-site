Clonando um repositório e editando pelo VS Code

Publicado em 24/07/2026 · #Git #VSCode

"Clonar" é só o nome técnico pra "baixar uma cópia completa do repositório pro seu computador". Depois disso, você edita os arquivos normalmente, como qualquer pasta, e manda as mudanças de volta pro GitHub quando quiser — sem precisar usar o site do GitHub pra editar nada.

1. Instalar o Git

O VS Code já vem com controle de versão embutido, mas ele depende do Git (o "motor" por trás) estar instalado no sistema. Baixe em git-scm.com/downloads e instale com as opções padrão — pode clicar "Next" em tudo.

2. Clonar o repositório

  1. Abra o VS Code
  2. Ctrl+Shift+P → digite "Git: Clone" → Enter
  3. Cole a URL do repositório, no formato https://github.com/seu-usuario/seu-repositorio.git
  4. Escolha uma pasta no seu computador pra salvar
  5. Quando perguntar, clique em "Open"

Pronto — o projeto inteiro agora existe também localmente, como uma pasta comum.

3. Configurar nome e e-mail (uma vez só)

O Git precisa saber quem está fazendo as alterações. Se aparecer um aviso pedindo pra configurar user.name e user.email, crie ou edite o arquivo .gitconfig na pasta do seu usuário do Windows (%USERPROFILE%) com:

[user]
    name = Seu Nome
    email = seu-email@exemplo.com

4. Editar, salvar, e enviar as mudanças

  1. Edite qualquer arquivo do projeto normalmente e salve (Ctrl+S)
  2. Abra o painel Source Control (Ctrl+Shift+G)
  3. Escreva uma mensagem curta descrevendo o que mudou
  4. Clique em Commit
  5. Clique em Sync Changes (ou "Push")

Na primeira vez que enviar, o VS Code pode abrir uma aba do navegador pedindo pra você autorizar o acesso à sua conta do GitHub — é só logar e autorizar uma única vez.

5. Trazer mudanças feitas pelo site do GitHub

Se você editar algum arquivo direto pela interface do GitHub (pelo navegador), seu computador não atualiza sozinho. Pra trazer essas mudanças pro VS Code:

  1. Painel Source Control → três pontinhos "..." → Pull

Ou clique no ícone de setas circulares 🔄 no rodapé do VS Code, que faz Pull e Push ao mesmo tempo.

Dica

Não precisa clonar de novo toda vez que abrir o VS Code — o clone é só a primeira vez. Nas próximas, é só File → Open Folder e escolher a mesma pasta, ou pegar nos "Recentes".

Cuidado

Evite editar o mesmo arquivo ao mesmo tempo pelo site do GitHub e localmente sem sincronizar entre um passo e outro — isso pode gerar um conflito, onde o Git não sabe qual versão manter. O ideal é sempre editar em um lugar por vez.
